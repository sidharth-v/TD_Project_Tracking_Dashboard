# Project Tracking Dashboard

## Files to upload to GitHub

- app.py
- requirements.txt
- .streamlit/config.toml

## Streamlit secrets

In Streamlit Cloud, add:

```toml
EXCEL_FILE_URL = "https://1drv.ms/x/s!YOUR_PERSONAL_ONEDRIVE_SHARE_LINK"
REFRESH_SECONDS = 60
```

Use a personal OneDrive share link with **Anyone with the link can view**.

Do not use an Excel browser edit/view URL.
